Privacy Policy

Last updated: October 10, 2026

Schoolmathtime is a browser-style web proxy with optional YouTube search and an optional connection to Google and YouTube account data. This policy explains what happens when you use the connection feature.

Information accessed through Google

If you choose Connect with Google, Schoolmathtime asks Google for permission to view basic Google profile information and read-only YouTube account data. It may receive your display name, email address, and YouTube channel name and identifier. The request uses Google's OAuth authorization-code flow with PKCE. Schoolmathtime never asks for or receives your Google password.

How account data is used

Account information is used only to show which account is connected and to enable read-only YouTube Data API features. Schoolmathtime does not sell this account information or use it for advertising. The access token is held on the application server and is not sent to browser JavaScript.

Storage and retention

The current implementation stores the short-lived OAuth state, access token, and displayed account details in server memory only. It does not write these values to a database or disk. The connection expires when the access token expires or the server restarts. Server memory is cleared on restart. A random session identifier is placed in a Secure (in production), HttpOnly, SameSite=Lax cookie.

Disconnecting and revocation

Use Disconnect in the YouTube account panel to clear the local session and ask Google to revoke the access token. If Google's revocation endpoint is temporarily unavailable, the Schoolmathtime session is still cleared; you can also review or remove access from your Google Account permissions.

Browsing and service-provider logs

When you browse websites through Schoolmathtime, the service must process the destination URL and request data to retrieve the page. The hosting provider may maintain routine infrastructure or security logs. Avoid entering sensitive or confidential information into proxied websites, and review each destination site's own privacy policy.

Google services

Use of Google's services is also subject to the Google Privacy Policy. Schoolmathtime's OAuth connection uses the YouTube Data API and requests read-only access; it does not create a signed-in browser session on the proxied YouTube website.

Questions and changes

This policy may be updated as Schoolmathtime features change. If you maintain or deploy your own copy, update this policy with your correct operator contact and data practices before enabling public OAuth access.
